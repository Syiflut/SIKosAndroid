# SIKosAndroid

Sistem Informasi Manajemen dan Pemesanan Kamar Kos berbasis mobile Android. Aplikasi ini dirancang untuk memudahkan para pencari kos dalam menemukan kamar yang sesuai, serta membantu pemilik kos dalam mengelola data kosan dan berkomunikasi langsung secara realtime.
